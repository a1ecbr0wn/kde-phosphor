# Changelog

## 1.0.0

Initial release.

- Global theme (`Plasma/LookAndFeel`, id `com.a1ecbr0wn.phosphor`): Phosphor
  colour scheme, stock Breeze icons and cursor (recoloured), Oxygen window
  decoration (falls back to Breeze if not installed), an original splash
  screen, DM Mono as the fixed-width font
- Standalone `Phosphor` colour scheme, usable without the rest of the
  theme
- Plasma desktop theme with panel/popup recolouring
- Desktop wallpaper and a separate lock screen wallpaper, both original
  photographs by the author
- `install.sh`, `apply.sh` (with `--restore`), `uninstall.sh` for local
  installation, with a settings backup taken before every switch away
  from your previous theme
